# Web Application Framework (WAF) - Spring 2025 Lab Task (15th March 2025)

- Download list of domain text file by clicking [here](/imgs/waf/domains.txt).

#### Part-1: File System Operations
1. Create a folder named "your_name_waf_lab_15mar".
2. Navigate into the folder and create a Node.js file named "file_ops.js".
3. In "file_ops.js", write code to programmatically create a subfolder named "storage" in the same directory as the .js file.
4. Write a code statement to create a file named "info.txt" inside the "storage" folder.
5. Write a code statement to write your full name into the "info.txt" file.
6. Write a code statement to read the data from "info.txt" (your full name) and display it on the console.
7. Write code to overwrite the content in "info.txt" with only the first letter of your first name and the first letter of your last name (e.g., "John Doe" becomes "JD").
8. Repeat step 6 to display the updated content.
9. Clear all data from the "info.txt" file.
10. Repeat step 5 to write your full name again.

#### Part-2: Domain Name Classification
You are provided with a file "domains.txt" containing a list of domain names (e.g., "example.com", "test.org", "site.edu"). Your task is to:
- Create three files named "COM.txt", "ORG.txt", and "EDU.txt".
- Read the domain names from "domains.txt".
- Determine the top-level domain (TLD) for each entry (e.g., .com, .org, .edu) and append it to the respective file (COM.txt, ORG.txt, EDU.txt). Ignore domains with other TLDs for this task.

#### Part-3: Asynchronous Function Execution
Your program should define and call six functions named `register`, `sendWelcomeMessage`, `login`, `fetchProfile`, `updateStatus`, and `logout`. Use the asynchronous `setTimeout` function to introduce delays in each. Each function should output a console message indicating task completion. Call these functions in the following order with the specified delays, and the last line of code should be `console.log("All operations finished!")`.

- `register` = delay of 2500 milliseconds (2.5 seconds)
- `sendWelcomeMessage` = delay of 3000 milliseconds (3 seconds)
- `login` = delay of 2000 milliseconds (2 seconds)
- `fetchProfile` = delay of 4000 milliseconds (4 seconds)
- `updateStatus` = delay of 1500 milliseconds (1.5 seconds)
- `logout` = delay of 3500 milliseconds (3.5 seconds)

i. Call these functions in the above order with the given delays and observe the execution order. Note the sequence in which messages appear.
ii. Use callbacks to ensure the functions execute in the specified order. Call them again with the same delays and verify the order.
iii. Use Promises to achieve the same ordered execution as in part ii. Call the functions with the delays and confirm the sequence.
iv. Use async/await to accomplish the same as part ii or iii. Call the functions with the delays and verify the execution order.

#### Part-4: Web Server with Logging and Dynamic File Updates
Create a web server using Node.js’s `http` module. Define five routes: `/`, `/students`, `/courses`, `/grades`, and `/events`. Maintain a log file "access_log.txt" using the `fs` module, appending an entry each time a URL is accessed. Each log entry should include a serial number, timestamp (date and time), URL, and the number of query parameters.

Create three plain text files: "students.txt", "courses.txt", and "grades.txt" using the `fs` module. Append data to these files based on query parameters from the respective routes:
- `/students` appends to "students.txt" with fields: `id`, `name`, `grade_level`, and `school`.
- `/courses` appends to "courses.txt" with fields: `id`, `course_name`, `credits`, and `instructor`.
- `/grades` appends to "grades.txt" with fields: `id`, `student_name`, `course_id`, and `score`.

Test your server by hitting at least 5 URLs with query parameters for each of the above routes, such as:
- `/students?id=101&name=Aisha&grade_level=10&school=CityHigh`
- `/courses?id=CS201&course_name=Programming&credits=3&instructor=DrSmith`
- `/grades?id=501&student_name=Aisha&course_id=CS201&score=85`
