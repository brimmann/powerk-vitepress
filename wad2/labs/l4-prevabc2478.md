# WAD, Spring 2025 - Lab 4 (March 20, 2025)

Read the description carefully.

### **Task Overview**

This task consists of three main parts:

1. **Detailed Gradesheet**

   - Create a table for displaying information about students, try to display diverse information with multiple data types.
   - Include at least 5 columns and 10 rows of sample data.
   - Use semantic elements of tables wherever possible.

2. **Conference Registration Form**

   - Create a form on the same page for adding a record of a student.
   - Use at least 5 different types of for elements.
   - Use semantic elements of forms wherever possible.
   - Add a **submit button**.

3. **Styling with CSS**

   - Use CSS to enhance the design and usability of both the table and the form.
   - Ensure a **clean, professional, and visually appealing layout**.
   - **Bonus points** for a more beautiful and user-friendly design.

4. **Additional Page Elements**
   - **Header**:
     - Contains a logo or the website name (aligned to the left).
   - **Footer**:
     - Displays a copyright message and your name.
   - **Short Report Section**:
     - Explain **what you did** and **why** in your own words.
     - Place this section before the footer.
