# WAD, Spring 2025 - Lab 5 (April 10, 2025)

Read the description carefully.

#### 1. **Create the Web Page Structure**

- Make a basic HTML page.
- Containing the following sections.
- It has to have two columns in the main content area
- Left column contain the following sections
- Right column contain multiple ads (an ad could a poster as image)

#### 2. **Header**

- At the top of the page, add a header.
- This could include the website name or a simple navigation menu (like moving to different sections).

#### 3. **Hero Section (Welcome Area)**

- Just below the header, add a large section to welcome visitors.
- Write things:
  - A welcome message (e.g., “Welcome to Our Site”).
  - A short description of the website or purpose.

#### 4. **Testimonials Section**

- Create a section titled “What People Say” or something similar.
- Use **Flexbox** to create **testimonial cards**.
- Each **testimonial card** must include:
  - Person’s **name**
  - Their **review**
  - Their **photo** (just use placeholder images)
  - Their **profession**

#### 5. **Report Section**

- Add a short paragraph or list describing the work you’ve done.

#### 6. **Footer**

- At the very bottom, add a footer.
- Include things like copyright, contact info, or simple links.

#### 7. **Page Layout Using CSS Grid**

- Use **CSS Grid** for the **overall page layout** (header, hero, testimonial section, report section, footer).
- Inside the testimonial section, use **Flexbox** to arrange the testimonial cards.
