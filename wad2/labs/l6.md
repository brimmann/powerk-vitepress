# WAD, Spring 2025 - Lab 6 (April 23, 2025)

This lab task has three parts. Each part should be done in separate HTML file.

**Submission Guidline:**
Create folder named `lab6` beside other lab tasks. It should contain three file:

- `explor.html` (For Part 1)
- `design.html` (For Part 2)
- `index.html` (For Part 3)

Finaly make your commit and push it to Github as usual.

## Part 1: Exploratory Mini Tasks

- Think about what each property does (like padding, margin, etc.)
- Check the Tailwind docs when you're not sure
- Try different values to see what happens

### 1. Using Flexbox

- Make a container with 3 boxes inside
- Arrange them in a row
- Try different ways to center them vertically and horizontally

### 2. Create a Grid Layout

- Make a container with 6 boxes
- Display them in 3 equal columns
- Add consistent spacing between all boxes

### 3. Control Margins, Padding and Size

- Padding on all sides
- Extra padding left/right
- Margin on all sides
- Extra margin on top
- Set both width and height

### 4. Style Text

- Write a paragraph with a title and:
  - Make the text larger and slightly bold
  - Change the color
  - Adjust the space between lines

### 5. Design a Box with Background and Border

- Create a box that has:
  - A background image that covers the whole box
  - A thick black border
  - Rounded corners

### 6. Style a Simple Table

- Make a table with headers and data rows
- Add borders around all cells
- Give all cells equal padding

### 7. Add Hover Effect

- Create a colored button
- Make it change color when mouse hovers over it

### 8. Use Custom Values

- Make a box with:
  - A very specific width (not standard size in TailwindCSS, in pixels)
  - Text in a custom color (using hex code)

### 9. Combine Multiple Styles

- Create a box with text that:
  - Is perfectly centered
  - Has padding all around
  - Has a light gray background
  - Changes to darker gray on hover
