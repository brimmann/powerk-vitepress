## Step-by-Step Demonstration

In this demo we are going create a basic static website using only HTML and we will practice how to use Git and GitHub to make our website online and store our code-base on GitHub.

### Creating our Website

To write HTML code we need to install VS Code on our machines. To do so, lets follow this guide:
- https://www.youtube.com/watch?v=B-s71n0dHUk

Once we have installed VS Code the next thing we need to do is to open a folder in VS Code and start writing our first website.

So let's create a folder named `wad-labs` and inside this folder create another folder named `lab1` and open it in VS Code. After that, create a new file named `index.html`. In this file write the following code.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=<device-width>, initial-scale=1.0" />
    <title>Document</title>
  </head>
  <body>
    <h1>Welcome to my First Website</h1>
    <p>
      My name is X and I'm student of Quaid-i-Azam Uinversity. I'm studying
      computer science. It is my 5th semester.
    </p>
  </body>
</html>
```

**Quick Explanation** 
- We just a created very basic HTML page.
- It has two tags a heading and a paragraph.

Now go to `lab1` folder in your system file explorer and open `index.html` in a browser to see your website.

So up to this point we have created our website, now we want to make it online so everyone from everywhere can open it using a link. For this purpose we have so many options available but we will use GitHub Pages. GitHub is a platform where people host their code-base but can also be used for hosting static web pages. So first let's host our code on GitHub and then make it online from there.


### Git and GitHub

Before we talk about GitHub let's briefly talk about what is Git. Git is like a time machine for your files. It helps you save different versions of your work as you make changes, so you can always go back to an earlier version if something goes wrong. Think of it as a super-organized way to track changes, collaborate, and never lose your progress!

First, you **tell Git to watch your folder**—like saying, "Hey, keep an eye on this project for me." Then, you **pick the stuff you want to save**—like saying, "Okay, save these changes I made." Finally, you **take a snapshot** of those changes and add a note, like, "This is where I fixed the bug." Now, you can always go back to that snapshot if you need to. It’s like saving checkpoints so you don’t lose your work!

Lets install Git on our system using the following guide:
- https://youtu.be/3FTficFKzME

 Once we installed Git, let's make our project use Git (to become a Git Repository):
 1. Open `wad-labs` folder in CMD/Terminal/PowerShell. To learn more about how we open a folder in CMD watch [this guide ](https://www.youtube.com/watch?v=QBWX_4ho8D4)
 2. Enter `git init` to tell Git that this folder should considered as a Git Repository. 
 3. Enter `git add .` to add our project's files and folder to Git and to tell Git to track changes in all folders and files in this folder.
 4. Enter `git commit -m 'initial commit'` to tell Git take a snapshot of our project at this point of time.

Now we are done with Git part. Next we need to store this repository on GitHub. Before we send a copy of our repository at this commit to GitHub we need to setup GitHub and connect it to Git on our computer. For that let's follow the following guides:
- [Creating a GitHub Account](https://www.youtube.com/watch?v=RnWDKWmaQ8s)
- [Adding SSH Key to GitHub Account](https://www.youtube.com/watch?v=snCP3c7wXw0)

Once we are done with creating GitHub account and connecting it to our Git we need to create new repository and push our code to it. For that let's follow the following guide:
- https://www.youtube.com/watch?v=RnWDKWmaQ8s


### Making our Website Online (Deploying)

Once you pushed the repository to GitHub, now let's online our websites using the following steps:

1. Go to our newly create repository on GitHub
2. Click on **Settings**
3. In **Settings** click on **Pages**
4. One the right side set the branch to **main** and click **Save**

This will enable our pages to be shown online. To see our first website to the following link:
- https://<your_username>.github.io/wad-labs/lab1/

## Lab Task

**Objective:**  
Create a simple, personalized website using basic HTML, version control it with Git, and make it live on the internet using GitHub Pages.

**Note:** Do not copy each other codes and don't generate AI code for the exercise.

**Steps:**

1. **Plan Your Website**  
   Think about what you want your website to showcase. It could be about yourself (like a digital resume), a hobby, or a favorite topic. Decide on at least three sections (e.g., "About Me," "Interests," "Contact").

2. **Create the Website**  
   - Use HTML to build a single webpage.  
   - Include at least these elements:  
     - A heading for your name or the site’s title.  
     - A paragraph introducing yourself or your topic.  
     - A list (ordered or unordered) of something meaningful to you (e.g., skills, favorite books, goals).  

3. **Set Up Git**  
   - Create a new folder on your computer for this project.  
   - Initialize it as a Git repository.  
   - Add your `index.html` file to the repository and make your first commit with a message like "Initial website setup."

4. **Push to GitHub**  
   - Create a new repository on GitHub (give it a clear name, like "my-website").  
   - Connect your local repository to the GitHub one and push your code to the remote repository.

5. **Make It Live with GitHub Pages**  
   - Go to your repository settings on GitHub.  
   - Find the section for GitHub Pages and enable it, selecting the main branch as the source.  
   - Wait a moment, then visit the provided URL to see your live site.

**Deliverables:**  
- A GitHub repository just like the one in Demo.  
- A live website accessible via GitHub Pages.  
- A brief description explaining what you did and why.
